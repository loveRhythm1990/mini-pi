# mini-pi 教程贡献检查单

1. 动手前先 read 目标章节的 README.md 和相邻章节的结构，确认补充的位置和文风；
2. 代码改动必须附带离线测试（假 Provider，不联网），并保证 `python3 scripts/test.py` 全绿；
3. 提交信息沿用仓库风格：`第 X 章……`，一行说清楚改了什么；
4. 引用 pi 源码时必须锁定提交号，用 `git grep` / `git show` 核对行号，禁止凭记忆引用；
5. 面向最终读者写作：陈述事实，不记录讨论过程，不用论战语气。

完成上述检查后，列出改动文件清单，等待用户确认再提交。
